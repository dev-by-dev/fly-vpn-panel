# Страница «Юзеры» и диалог пользователя в стиле Remnawave

## Задача

Страница «Юзеры» была простой таблицей, диалог создания — узкой формой в одну
колонку. Нужно как в Remnawave: ряд карточек статистики, аккуратная таблица и
двухколоночный диалог с секциями.

## Решение

`web/src/routes/Users.svelte`:

- заголовок «Пользователи» + кнопки «Обновить» / «Добавить»;
- 5 карточек: Всего, Активные, Истекли, Квота, Отключены — иконка в тонированном
  квадрате, подпись, крупное число. Классификация: `active` — не отключён,
  `expired` — причина `expired`, `limited` — `quota`, остальные — `disabled`;
- таблица: точка статуса + имя, ID, статусная плашка заглавными, онлайн,
  истекает, полоса прогресса трафика (`used / quota|∞`, красная при ≥90%),
  действия.

`web/src/lib/components/UserDialog.svelte`:

- модалка `max-w-3xl`, две колонки на `md+`;
- секции с иконками: «Данные пользователя», «Устройства» / «Трафик и лимиты»,
  «Настройки доступа»;
- шапка с ✕, футер «Отмена» / «Создать (Сохранить)».

Полей Telegram/Email/тегов/сквадов в панели нет — не добавлялись.

## Проверка

- `svelte-check` — 0 ошибок (12 старых предупреждений).
- `npx vitest run` — 22/22; тесты `Users.test.ts` обновлены под новые плашки
  (заглавные), полосу трафика и заголовок диалога.
- Браузер: скриншоты страницы и диалога совпадают с макетом.

## Вне рамок

- Фильтры по колонкам, выбор строк, массовые операции, страны/ноды — в панели
  нет соответствующих данных.
