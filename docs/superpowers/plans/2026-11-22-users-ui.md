# The «Юзеры» page and the user dialog in Remnawave style

## Task

The «Юзеры» page was a plain table, the creation dialog a narrow single-column
form. It needs to work like Remnawave: a row of stat cards, a tidy table and a
two-column dialog with sections.

## Solution

`web/src/routes/Users.svelte`:

- a «Пользователи» heading + «Обновить» / «Добавить» buttons;
- 5 cards: `Всего`, `Активные`, `Истекли`, `Квота`, `Отключены` (UI labels) — an icon in a tinted
  square, a caption, a large number. Classification: `active` — not disabled,
  `expired` — reason `expired`, `limited` — `quota`, everything else `disabled`;
- the table: status dot + name, ID, an uppercase status badge, online, expires,
  a traffic progress bar (`used / quota|∞`, red at ≥90%), actions.

`web/src/lib/components/UserDialog.svelte`:

- a `max-w-3xl` modal, two columns at `md+`;
- sections with icons: «Данные пользователя», «Устройства» / «Трафик и лимиты»,
  «Настройки доступа»;
- a header with ✕, a footer «Отмена» / «Создать (Сохранить)».

The panel has no Telegram/Email/tags/squads fields — they were not added.

## Verification

- `svelte-check` — 0 errors (12 pre-existing warnings).
- `npx vitest run` — 22/22; the `Users.test.ts` tests updated for the new badges
  (uppercase), the traffic bar and the dialog heading.
- Browser: screenshots of the page and the dialog match the mockup.

## Out of scope

- Column filters, row selection, bulk operations, countries/nodes — the panel has
  no such data.
