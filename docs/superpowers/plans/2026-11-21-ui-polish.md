# Dashboard: chart layout and even block sizing

Branch: `ui-polish-20261121-02` (from `dev`).
Symptom (in the user's words): "Dashboard menu. Everything is kind of crooked and uneven" — the chart
legend overlapped the canvas, Y-axis labels looked like "0 000", cards overlapped the chart.

## Causes

1. The uPlot CSS was not imported anywhere in the project. Without `uPlot.min.css` the `.uplot`
   container is not positioned, the axis and legend are drawn over the canvas and neighboring cards.
2. The chart width was set once in `onMount` from `el.clientWidth`. On any window
   resize the chart kept the old width and pushed the card apart; `main` in a flex layout without
   `min-w-0` produced horizontal page scroll.
3. `$effect` read `buckets` only inside `if (chart)`. On the first render `chart === null`,
   so `buckets` did not get into the effect's dependencies and the chart stayed forever with an empty
   dataset `[[0],[0],[0]]` — hence the 1970 time scale and "0 000" on Y.
4. The empty state was missing there too: with no data the 1970s scale was shown.

## Changes

- `web/src/lib/components/TrafficChart.svelte`
  - import `uplot/dist/uPlot.min.css`;
  - `ResizeObserver` in `onMount` → `chart.setSize(...)`; release in cleanup;
  - `$effect` reads `toSeries(buckets)` outside the condition, then `setData` if the chart is already created;
  - Y-axis labels and series values are formatted with `fmtBytes` (КБ/МБ/ГБ instead of "0 000");
  - empty dataset: the chart itself is hidden, «Нет данных за период» is shown.
- `web/src/App.svelte` — `<main class="min-w-0 flex-1 p-6">` so the content does not stretch the flex.
- `web/src/routes/Dashboard.svelte` — card grids are adaptive: `sm:grid-cols-3`,
  `lg:grid-cols-2`.
- `internal/api/router_test.go` — `TestSPAFallback` checks the stable marker `<div id="app">`
  instead of the `build me` placeholder (dist/index.html overwrites it after a build, so the test failed).

## Verification

- 1280×900, 1024×900, 1440×900: `document.documentElement.scrollWidth === innerWidth`
  (no horizontal scroll), chart width equals card width (974 → 718 on resize).
- Empty DB: «Нет данных за период», no 1970 scale.
- 24 buckets per day: real line, Y axis in `МБ` (UI unit string), X axis with dates/hours, legend under the chart.
- `npm run check` — 0 errors (12 pre-existing `state_referenced_locally` warnings);
  `npx vitest run` — 8 files / 22 tests; `go test ./...` — ok.

## Out of scope

- Mobile width (~390px): horizontal scroll remains, mobile layout is not the goal.
- Other UI pages — per the user's next items.
