# Дашборд: вёрстка графика и равномерность блоков

Ветка: `ui-polish-20261121-02` (от `dev`).
Симптом (со слов пользователя): «Меню Дашборд. Как то все криво и неравномерно» — легенда
графика наезжала на полотно, подписи оси Y в виде «0 000», карточки перекрывались графиком.

## Причины

1. CSS uPlot не импортировался нигде в проекте. Без `uPlot.min.css` контейнер `.uplot`
   не позиционируется, ось и легенда рисуются поверх полотна и соседних карточек.
2. Ширина графика выставлялась один раз в `onMount` по `el.clientWidth`. При любом ресайзе
   окна график оставался старой ширины и распирал карточку; `main` во flex-раскладке без
   `min-w-0` давал горизонтальный скролл страницы.
3. `$effect` читал `buckets` только внутри `if (chart)`. При первом рендере `chart === null`,
   поэтому `buckets` не попадал в зависимости эффекта и график навсегда оставался с пустым
   датасетом `[[0],[0],[0]]` — отсюда шкала времени 1970 года и «0 000» по Y.
4. Там же отсутствовало пустое состояние: при отсутствии данных показывалась шкала 1970-х.

## Изменения

- `web/src/lib/components/TrafficChart.svelte`
  - импорт `uplot/dist/uPlot.min.css`;
  - `ResizeObserver` в `onMount` → `chart.setSize(...)`; освобождение в cleanup;
  - `$effect` читает `toSeries(buckets)` вне условия, затем `setData`, если график уже создан;
  - подписи оси Y и значения серий форматируются `fmtBytes` (КБ/МБ/ГБ вместо «0 000»);
  - пустой датасет: сам график скрыт, показывается «Нет данных за период».
- `web/src/App.svelte` — `<main class="min-w-0 flex-1 p-6">`, чтобы контент не распирал flex.
- `web/src/routes/Dashboard.svelte` — сетки карточек адаптивные: `sm:grid-cols-3`,
  `lg:grid-cols-2`.
- `internal/api/router_test.go` — `TestSPAFallback` проверяет стабильный маркер `<div id="app">`
  вместо placeholder `build me` (dist/index.html после сборки его перезаписывает, тест падал).

## Проверка

- 1280×900, 1024×900, 1440×900: `document.documentElement.scrollWidth === innerWidth`
  (горизонтального скролла нет), ширина графика равна ширине карточки (974 → 718 при ресайзе).
- Пустая БД: «Нет данных за период», без шкалы 1970 года.
- 24 бакета за сутки: реальная линия, ось Y в МБ, ось X с датами/часами, легенда под графиком.
- `npm run check` — 0 ошибок (12 предсуществующих warning'ов `state_referenced_locally`);
  `npx vitest run` — 8 файлов / 22 теста; `go test ./...` — ok.

- Мобильная ширина (~390px): горизонтальный скролл остаётся, мобильная вёрстка не цель.
- Прочие страницы UI — по следующим пунктам пользователя.
