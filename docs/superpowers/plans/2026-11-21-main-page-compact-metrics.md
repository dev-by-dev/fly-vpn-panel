# Компактные карточки метрик сервера

Ветка: `main-page-compact-20261121-04` (от `dev`)
Предыдущий шаг: `main-page-20261121-03` (горизонтальные вкладки + метрики)

## Задача

Пользователь: «Зачем такие большие рамки для данных? Сделай их меньше размером.
Чтобы туда вмещалась информация и свободного места было по минимуму в них».

Карточки блока «Сервер» были растянуты на всю ширину строки (grid из 4 колонок,
`p-4`, значение `text-xl`) — при 1440px каждая ~340×110 px, содержимое занимало
меньшую часть.

## Решение

- `grid sm:grid-cols-2 xl:grid-cols-4` → `flex flex-wrap gap-2`: карточка шире
  контента, но не растягивается.
- Паддинг `p-4` → `px-3 py-2`, радиус `rounded-xl` → `rounded-lg`.
- Подпись и значение в одну строку (`flex items-baseline gap-2`), значение
  `text-xl` → `text-lg leading-none`; вторая строка (детали) осталась `text-xs`.
- Вёрстка/данные не менялись, API и backend не тронуты.

Итог при 1440px: карточки 167×57, 117×57, 221×57, 196×57 вместо ~340×110.

## Проверка

- Браузер (vite dev :5199): строка карточек 57 px высотой, каждая шире контента,
  горизонтального скролла нет (`scrollWidth` = 1440).
- `npm run check`, `npx vitest run`, `go test ./...`.

## Вне рамок

- Карточки «Трафик панели» ниже не трогались — замечание было только про «Сервер».
- Мобильная ширина < 640px по-прежнему переносится по одной карточке (flex-wrap).
